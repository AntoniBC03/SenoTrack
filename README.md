## 🌟 Overview

**SenoTrack** is a modern, open-source web application designed to streamline data processing and visualization. Built with a sleek dark-mode UI, it offers dynamic multi-language support to cater to global developers and data professionals.

### ✨ Key Features
* 🌍 **Global i18n Support:** Instant switching between English, Portuguese, Spanish, Mandarin, and German.
* 🎨 **Custom Executive UI:** Tailored CSS over standard Streamlit components for a premium dark-mode experience.
* ⚡ **Fast & Responsive:** Lightweight architecture for quick deployment and execution.
* 🔓 **100% Open Source:** Free to use, adapt, and contribute under the MIT License.
